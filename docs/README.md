# PAJIN Documentation

This directory contains only documentation that must remain reviewable and versioned with code.
Read the [documentation authority policy](DOCUMENTATION_POLICY.md) before adding or relocating a
document. Product direction, priorities, current progress, and blockers live in the
[PAJIN Notion roadmap](https://app.notion.com/p/3a94b2ea35f081329974c7f57eda299a).

## Writing rule

Use one canonical English Markdown file per subject. Do not create `.en.md` or `.ko.md` siblings
and do not store roadmap or progress snapshots in this directory. A later documentation website
should be generated from these canonical sources.
